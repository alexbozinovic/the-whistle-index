The Whistle Index

Methodology

Bias does not mean intent. Bias means measurable advantage. This project measures officiating patterns, statistical fingerprints, and game impact using public NBA data.

What This Site Measures

The model tracks how foul and free-throw patterns shift game shape, then converts those patterns into referee-first signals. A high score indicates a larger measurable officiating footprint, not proof of wrongdoing.

  • Whistle volume and asymmetry across both teams
  • Fourth-quarter and clutch whistle shifts
  • Home-away lean in foul and free-throw components
  • Crew-level game control footprint

What This Site Does Not Claim

  • It does not prove corruption.
  • It does not prove intent.
  • It does not claim league direction.
  • It does not label a single call as definitive evidence.

Current MVP Model (v0)

The first model uses equal-weight components so outputs stay transparent while the pipeline is validated. Scores are expected to evolve as context controls are added. 

Team Whistle Lean (home)
= average(
  free_throw_edge,
  foul_burden_relief,
  fourth_quarter_edge,
  clutch_edge
)

Crew Impact Score
= average(volume_score, imbalance_score)
